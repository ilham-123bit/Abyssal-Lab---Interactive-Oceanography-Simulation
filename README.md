# Abyssal Lab — Interactive Oceanography Simulation

## Overview

Abyssal Lab is an oceanography website concept for pre-university students. It aims to pair a cinematic 3D ocean scene with a scientific dashboard to make oceanographic processes easier to explore and understand.

## Intended features

The planned experience is to:

- present an interactive 3D ocean environment;
- pair the scene with a dashboard that explains selected oceanographic processes; and
- connect visual changes in the scene with scientific concepts and context.

These are project goals, not completed interactions or validated educational materials.

## Current status

The website is in development. This repository currently contains a project description only; it does not yet include a working website, deployed experience, screenshots, or runnable setup instructions.

## Scope

The intended audience is pre-university learners. The project is an educational visualization concept, not a scientific forecasting or operational oceanography tool.
